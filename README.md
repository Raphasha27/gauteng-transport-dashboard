# Gauteng Transport Dashboard

**Transport intelligence dashboard for Gauteng, South Africa — ML predictions, geospatial analysis, and AI-powered insights.**

Built with Streamlit, this dashboard provides real-time transport analytics, route optimization, delay prediction, and an AI assistant for the Gauteng public transport network.

## Features

- **ML Predictions** — Delay forecasting using scikit-learn models
- **Geospatial Visualization** — Interactive maps with pydeck
- **AI Assistant** — Local LLM-powered Q&A via Ollama
- **Report Generation** — Automated PDF reports with fpdf2
- **Real-time Analytics** — Plotly dashboards for transport metrics

## Quick Start

```bash
git clone https://github.com/Raphasha27/gauteng-transport-dashboard.git
cd gauteng-transport-dashboard
pip install -r requirements.txt
streamlit run streamlit_app.py
```
